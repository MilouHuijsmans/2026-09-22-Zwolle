Python

Python is een populaire programmeertaal voor onderzoek en andere toepassingen. We zullen Python gebruiken in een JupyterLab omgeving via het programma Anaconda.

JupyterLab is een programmeeromgeving die werkt in een internet browser. JupyterLab zullen we installeren met Anaconda. Het is belangrijk dat je een up-to-date internet browser gebruikt. De meest recente versies van Chrome, Safari en Firefox worden ondersteund. Internet browsers zoals Internet Explorer of Edge worden mogelijk niet ondersteund.

  1. Open https://www.anaconda.com/download/ in jouw internet browser.
  2. Download de Graphical Installer van Anaconda Distribution voor Windows
  3. Dubbelklik op het gedownloade bestand (bijvoorbeeld, Anaconda3-2025.12-2-Windows-x86_64.exe)
  4. Volg de instructies met alle standaard opties behalve zorg ervoor dat er een vinkje staat bij Add Anaconda to my PATH environment variable.

  2. Download de Graphical Installer van Anaconda Distribution voor Mac
    De volgende stappen maken gebruiken van de shell. Als je niet comfortabel bent met het zelf uitvoeren van de installatie, stop dan hier en vrag om hulp tijdens een inloopsessie. .
  3. Open een terminal window en navigeer naar de map waar het installatiebestand is gedownload (bijvoorbeeld, cd ~/Downloads).
  4. Type 
    bash Miniforge3-
    en druk dan op Tab om het volledige bestandsnaam automatisch aan te vullen. De naam van het bestand dat je zojuist hebt gedownload zou nu moeten verschijnen. Druk Enter (of Return afhankelijk van jouw toetsenbord).
  5. Volg de tekst prompts in de terminal. Om door de tekst te gaan, druk Spatiebalk.
    • Type yes en druk Enter (of Return) om de license goed te keuren.
    • Druk Enter (of Return) om de standaardlocatie van de bestanden goed te keuren.
    • Type yes en druk Enter (of Return) om Anaconda toe te voegen aan jouw PATH (hierdoor wordt de Anaconda distribution de standaard voor Python).

De download voor Anaconda Distribution kan gevonden worden op https://www.anaconda.com/download/.

De installatieprocedure is afhankelijk van jouw Linux Distribution. Als je niet comfortabel bent met het zelf uitvoeren van de installatie, stop dan hier en vraag om hulp tijdens een inloopsessie.
